LiyeBox Technical Specifications

This page publishes the current official specification sheet for the LiyeBox handheld gaming console. Values marked as preliminary may change before mass production.

ModelLiyeBox LYB-2026-128 handheld cloud gaming console
Processor4 nm octa-core ARM platform: 1 performance core up to 3.1 GHz, 3 balanced cores up to 2.6 GHz, 4 efficiency cores up to 2.0 GHz
GraphicsIntegrated mobile GPU with hardware video decode for AV1, HEVC, and VP9; cloud-streaming latency assist pipeline for 1080p/60 fps sessions
Memory8 GB LPDDR5X system memory
Storage128 GB UFS 3.1 internal storage, microSD expansion up to 1 TB
Display7-inch OLED, 1920 x 1080 resolution, 120 Hz refresh rate, 800 nits typical brightness, capacitive multi-touch
Battery58 Wh lithium-polymer pack; up to 12 hours cloud streaming under controlled Wi-Fi brightness test; local 3D play time varies by title and thermal profile
ChargingUSB-C Power Delivery, 45 W maximum input, 0-50% charge target in about 35 minutes under lab conditions
WirelessWi-Fi 6E, Bluetooth 5.3, optional 5G hotspot tethering support through companion device
ControlsDual analog sticks, D-pad, ABXY buttons, L/R bumpers, analog triggers, menu buttons, six-axis motion sensor
AudioStereo speakers, dual microphone array, 3.5 mm headset jack, Bluetooth audio support
PortsUSB-C charging/data, microSD slot, 3.5 mm audio
SoftwareLiye OS based on Android Open Source Project, native Android game support, browser-based cloud gaming portal, OTA updates
Dimensions270 mm x 112 mm x 19.8 mm, preliminary industrial design target
WeightApproximately 430 g, preliminary engineering sample target
WarrantyOne-year limited hardware warranty in launch regions
Transparency note: this is an official preliminary specification page, not an independent lab result. Battery life, display brightness, and thermals should be verified again when production hardware is available.
