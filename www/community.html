LiyeBox Community and User Discussion

This page documents where user discussion should live and how community feedback should be treated. Public discussions should not be simulated; they should be linked once they exist.

Reddit discussions

No official Reddit thread is listed yet. When users begin discussing LiyeBox, link to real threads with visible dates, usernames, criticism, and follow-up responses.

Release notes pending

Firmware updates

Publish firmware release notes with version number, release date, fixed issues, known issues, and rollback guidance. This is one of the strongest signs that hardware is actively maintained.

Feedback policy

User feedback

Community feedback should include positive and negative reports. Visible handling of latency, battery, stick calibration, and account issues is more credible than perfect praise.
